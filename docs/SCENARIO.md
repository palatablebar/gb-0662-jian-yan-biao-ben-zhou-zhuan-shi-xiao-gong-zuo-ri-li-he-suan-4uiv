# 检验科复核工作流

常规检验外包中转遇到周末与法定休息日，暂停审批还可能重复。科室不能用签发减接收的自然分钟直接判定常规违约，也不能把急诊跟普通标本套同一日历。

样例包含42条标准标本，脏台账加入重复签发、冲突签发、未知项目、错误急诊标志、缺失接收和时序倒置。000006标本从11月2日16:00到11月4日10:00，11月3日休息，工作分钟120；两条重叠批准暂停合并后仅扣30，净90。000030为急诊，同跨度按自然分钟2520减批准暂停30，净2490。

两条重叠的交接暂停实际由住院与检验科共同批准。裁决是共同承担而非记在申请科室：合并后的30分钟只从标本净用时扣一次，住院与检验科各承担15分钟；000006责任净用时仍为90（住院），责任合计120=90+30，检验科责任用时15。标本净用时、暂停扣除与责任用时三者在责任用时页并排核对，任一不平都会阻止复核签发。

数据专员依次确认仪器来源、项目规则与工作日历，查看标本时效及暂停扣除证据，在异常隔离保留原始字段，在责任用时页核对标本净用时与各责任科室用时并排一致，按科室对账后签发批次复核。交接暂停改动会同步重算标本结论与责任结论并产生新批次；更换现行责任结论失败时恢复旧版，重跑同一核对不新增责任记录。所有页面的数量均来自后端计算。
